# Akash Joseph — Personal Website

A single-page personal website for EE461L HW4, built with HTML and CSS.
Experience and project descriptions are intentionally general.

Website: https://akjo138.github.io/

Open `index.html` in a browser to preview locally. No installation or build is required.

## Assignment requirements

- `index.html` links to the external `stylesheet.css` file; no JavaScript is used.
- Tag selectors such as `body` and `h1` apply styles.
- Classes such as `.section` and `.project-card` are reused and styled.
- The `contact` ID is styled with `#contact`.
- Multiple `<div>` elements organize the page into sections.
- Links point to GitHub and LinkedIn, and `a:hover` changes link color.
- Padding, margins, and borders demonstrate the CSS box model.
- A local SVG illustration is included with an `<img>` tag and descriptive alt text.
- A description meta tag summarizes the page.

For deployment, configure GitHub Pages to deploy from the `main` branch and
the `/ (root)` folder in the repository's **Settings → Pages**.
